# datasource-sk-2A-7-5-VVVVV

A third-party avatar model as its author distributed it, with editable scenes, layered textures, and desktop and standalone-headset variants.

![SK_2A_7_5 VVVVV](e0ade52e-6a9d-4da1-8128-7cadd90aae76_base_resized.jpg)

## What it is for

It is source data: the author's packages, scene files, layered textures and preview images, kept together so the avatar can be converted and re-exported.

## Build and run

There is nothing to build; the files are read as they are.
